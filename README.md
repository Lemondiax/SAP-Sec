# SAP-Sec
SAP SECURITY GRC
Diseño e implementación de un nuevo modelo de roles y remediación de riesgos de Segregación de Funciones (SoD) para una empresa del sector [Industria, ej: Retail] con más de 2.000 usuarios, logrando mitigar riesgos críticos y automatizar el proceso de aprobación mediante SAP GRC Access Control
